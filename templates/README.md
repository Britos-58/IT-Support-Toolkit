# Standardized IT Templates

This directory contains blank templates for common IT operations. Standardization ensures that critical information is gathered uniformly, reducing back-and-forth communication and accelerating resolution times.

## Included Templates
- **Support Ticket:** Standard format for end-user requests.
- **Bug Report:** Used when escalating software defects to the Development team.
- **Troubleshooting Log:** For documenting deep-dive technical investigations.
- **Change Request (RFC):** For submitting infrastructure changes to the Change Advisory Board (CAB).
- **Post-Incident Report (PIR):** For documenting Major Incidents after resolution.
