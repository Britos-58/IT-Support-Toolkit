## 🎯 The "Shift-Left" Strategy & KCS
- **Shift-Left:** The practice of moving issue resolution as close to the end-user as possible. (e.g., Tier 3 writes a guide so Tier 1 can fix it -> Tier 1 writes an FAQ so the User can fix it themselves).
- **KCS (Knowledge-Centered Service):** A methodology where technicians update the Knowledge Base *as a byproduct* of solving tickets. If a ticket comes in and there is no KB article for it, the technician writes one after resolving the issue.
- **Goal:** Reduce MTTR (Mean Time To Resolve) and prevent the Helpdesk from answering the exact same question 50 times a week.
