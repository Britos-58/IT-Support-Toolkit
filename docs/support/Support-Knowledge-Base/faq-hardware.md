# Hardware FAQs & Quick Fixes

This document contains rapid troubleshooting steps for common hardware and peripheral complaints.

## 1. External Monitors & Docking Stations
**Q: "My second monitor says 'No Signal'."**
- **Quick Fix:** 
  1. Verify the monitor is powered on and set to the correct input source (e.g., HDMI vs. DisplayPort).
  2. Disconnect and reconnect the USB-C cable from the laptop to the docking station.
  3. Press `Win + P` and ensure the projection setting is set to **Extend**, not *PC screen only*.
  4. If using a DisplayLink dock, ensure the DisplayLink Manager software is running.

## 2. Audio & Headsets
**Q: "People can't hear me on Microsoft Teams / Zoom."**
- **Quick Fix:**
  1. Check the physical mute button on the headset cable or boom mic.
  2. Click the Speaker icon in the Windows taskbar and verify the correct output/input device is selected (e.g., *Jabra Evolve* instead of *Realtek Audio*).
  3. In Teams/Zoom settings, make a test call to verify microphone input levels.
  4. Check Windows Privacy Settings: Settings -> Privacy -> Microphone -> Ensure "Allow desktop apps to access your microphone" is turned ON.

## 3. Laptops & Power
**Q: "My laptop won't turn on at all, completely dead."**
- **Quick Fix (Static Discharge / Hard Reset):**
  1. Unplug the AC adapter and remove all peripherals (USB drives, docks).
  2. Press and hold the laptop's Power Button for **30 to 60 seconds** to drain residual flea power.
  3. Plug the AC adapter directly into the laptop (bypass the dock) and a known-good wall outlet.
  4. Press the power button. If the charging light turns on but the screen is black, shine a flashlight on the screen to check for a dead backlight.

## 4. Peripherals (Mouse / Keyboard)
**Q: "My wireless mouse is lagging or jumping across the screen."**
- **Quick Fix:**
  1. Replace the batteries. Low voltage causes erratic Bluetooth/RF behavior.
  2. Move the USB dongle to a port closer to the mouse (avoid plugging it into the back of a desktop tower where metal blocks the signal).
  3. Clean the optical sensor on the bottom of the mouse with a microfiber cloth.
