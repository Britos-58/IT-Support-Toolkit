## 🛠️ Essential Built-in Tools
Before installing third-party software, utilize Windows built-in diagnostic tools:
- **Task Manager (`taskmgr`)**: Quick view of processes and performance.
- **Resource Monitor (`resmon`)**: In-depth view of CPU, Memory, Disk, and Network.
- **Event Viewer (`eventvwr.msc`)**: System and Application logs.
- **Computer Management (`compmgmt.msc`)**: Centralized console for disks, services, and local users.

> 🔗 **External Resource:** [Microsoft Sysinternals Suite](https://learn.microsoft.com/en-us/sysinternals/) (Advanced troubleshooting tools like Process Explorer and AutoRuns).
