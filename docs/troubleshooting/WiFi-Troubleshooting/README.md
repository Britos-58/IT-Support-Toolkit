# Wi-Fi Troubleshooting Guide

Welcome to the Wi-Fi Troubleshooting Guide. Wireless networks are highly susceptible to environmental factors, client configuration issues, and roaming failures. This module covers how to diagnose and resolve common enterprise and remote-worker Wi-Fi issues.

## 📂 Table of Contents
- [Connectivity Issues](connectivity.md) - Authentication failures, Captive Portals, and IP issues.
- [Signal & Range](signal.md) - Dead zones, RSSI, and 2.4GHz vs 5GHz bands.
- [Interference & Channels](interference.md) - Co-channel interference, physical barriers, and rogue APs.

## 🛠️ Essential Wi-Fi Diagnostic Tools
- **`netsh wlan`**: Built-in Windows command-line tool for managing wireless profiles and generating reports.
- **Wi-Fi Analyzer apps**: Mobile or desktop apps (like Ubiquiti WiFiman or NetSpot) to visualize channel overlaps and signal strength.
- **Access Point (AP) Controller**: Dashboard (e.g., Cisco Meraki, Aruba, UniFi) to check client health from the infrastructure side.
