# Troubleshooting Decision Tree

Welcome to the Troubleshooting Decision Tree module. This section provides a logical, step-by-step workflow to help IT Support Technicians categorize, diagnose, and route incoming issues accurately and efficiently.

## 📂 Table of Contents
- [The Decision Tree](decision-tree.md) - Step-by-step diagnostic logic flow.
- [Routing & Escalation Matrix](escalation-path.md) - Where to send the ticket if Tier 1 cannot resolve it.

## 🎯 Purpose of the Decision Tree
A standardized decision tree prevents "guesswork" and ensures that every technician follows the same logical path. It helps in:
1. Identifying if the issue is a global outage or a local problem.
2. Categorizing the issue correctly (Hardware, Software, Network, Access).
3. Reducing the Time-to-Resolution (TTR) by asking the right questions first.
