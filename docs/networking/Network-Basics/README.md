## 🎯 Core Concepts
- **LAN (Local Area Network):** A network confined to a small geographic area (e.g., a single office building).
- **WAN (Wide Area Network):** A network that covers a broad area (e.g., the Internet, or a corporate network connecting offices in different countries).
- **The OSI Model:** As referenced in our Troubleshooting Guide, networking is built on layers, primarily Layer 2 (Data Link / MAC Addresses) and Layer 3 (Network / IP Addresses).
