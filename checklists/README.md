# Standard Operating Procedures (SOPs) & Checklists

Welcome to the Checklists directory. In enterprise IT, relying on memory for routine tasks leads to security vulnerabilities and operational failures. This module contains standardized checklists to ensure consistency and compliance across all IT operations.

## 📂 Available Checklists
- **[User Onboarding](User-Onboarding-Checklist.md)** - Account creation, licensing, and hardware provisioning.
- **[User Offboarding](User-Offboarding-Checklist.md)** - Access revocation and asset retrieval (Crucial for IAM Security).
- **[PC Diagnostics](PC-Diagnostic-Checklist.md)** - Standard hardware and OS troubleshooting steps.
- **[Network Diagnostics](Network-Diagnostic-Checklist.md)** - Step-by-step connectivity isolation.
- **[Software Deployment](Software-Deployment-Checklist.md)** - Pre-flight checks for pushing software via SCCM/Intune.
- **[Incident Response](Incident-Response-Checklist.md)** - Actions to take during a P1/P2 Major Incident.

## 🎯 Purpose
By following these checklists, technicians ensure that:
1. **Security** policies are strictly enforced.
2. **Audits** (like SOC 2 or ISO 27001) are passed easily because processes are documented and repeatable.
3. **Time-to-Resolution (TTR)** is reduced by eliminating guesswork.
